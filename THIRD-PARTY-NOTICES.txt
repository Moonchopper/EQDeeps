EQDeeps - Third-Party Notices
=============================

EQDeeps itself is under the MIT Licence; that grant covers EQDeeps' own code and
nothing else. This file carries the notices the licences of the bundled
components require, and every one of those components stays under its own
licence. NOTICE is the readable summary of where each piece came from; this is
the licence text behind it.

Two things are deliberately not reproduced here:

  * The .NET runtime's own third-party notices. A self-contained build lays the
    whole runtime down beside the app, so each runtime pack's LICENSE and
    THIRD-PARTY-NOTICES are copied verbatim into licenses\ at publish time
    (the PublishLicenseNotices target in src/EQDeeps.Server).
  * Anything EQDeeps only reads on the player's own machine - the EverQuest
    client's spell, map and item files. Those are read where they already sit
    and are never redistributed.

Keeping it current: this file is maintained by hand from the licence text each
component ships, and it moves with NOTICE in the same commit. The web list below
is what the SPA build actually links, measured from a sourcemapped `vite build`
rather than read off package.json - the dependency tree also carries Node-only
packages for @microsoft/signalr that never reach the browser bundle, and listing
those would be a claim about the binary that isn't true.
