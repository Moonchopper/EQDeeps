# The EQDeeps name and icon

The [MIT Licence](LICENSE) covers EQDeeps' code. It does not cover the name
"EQDeeps" or the app's icon, and this file says what that means in practice,
because MIT itself is silent on the subject and silence is not an answer anyone
can act on.

There is no registration behind this — only the rights that come from using the
name. Registering it would be a poor idea regardless: "EQ" belongs to Daybreak
Game Company, and this project has no business staking a claim near it.

## What you can do without asking

- Redistribute EQDeeps unmodified, under its own name, in any context including
  a commercial one. That is what MIT is for.
- Say truthfully what your thing is: "a fork of EQDeeps", "imports EQDeeps
  dashboards", "works with EQDeeps". Referring to a project by its name to
  describe a real relationship is ordinary and fine.
- Write about it, screenshot it, package it, put it on a list of tools.

## What to do instead

**If you distribute a modified build, give it your own name.** Not because the
changes are unwelcome — the licence invites them — but because someone who
downloads "EQDeeps" and gets different numbers has no way to know which project
to report the bug to, and the whole value of a parser is that its numbers can be
trusted. Rename the app, and say in your description that it started here.

Please also don't use the name or icon in a way that suggests this project
endorses, maintains, or has checked your work when it hasn't.
